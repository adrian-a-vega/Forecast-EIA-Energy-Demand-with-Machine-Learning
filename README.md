# Forcast Energy Information Administration(EIA) Demand with Machine Learning(ML)
## Description
Using the hourly electricity demand data from EIA to interpret eXtreme Gradient Boosting(XGBoost) predictions. 
- XGBoost is a supervised ML algorithm, specifily a gradient boosted decision trees(GBDT)

## Libraries 
1. Pandas
2. Numpy
3. Matplotlib
4. Seaborn
5. Scikit-learn
6. Xgboost

## Acquire EIA API Key
Visit: [Energy Information Administration Open Data](https://www.eia.gov/opendata/documentation.php?utm_source=chatgpt.com)
- Click the "Register" link on Right hand side.
- API will be emailed to the email address you provide.
